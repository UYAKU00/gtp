## 一条贯穿全文的结论

**拟合得好、参数正确、预测可靠，是三个不同的问题。**

- 多个参数可能互相补偿，生成几乎相同的血压曲线。
- 缺失的几何、边界条件或模型物理，会被拟合参数吸收。
- 代理模型能快速重复错误；物理残差小也不能自动证明参数可信。
- 最有说服力的验证需要参数空间检验、输出空间检验和独立观测三方面证据。

# 跨论文综合：从血压拟合走向可信参数反演

本文是基于六篇论文的**读者综合与研究建议**，不是任何一篇论文的译文，也不是已经运行的实验。

## 2. 为什么血压拟合不等于参数恢复

把模型写成 $y=F(\theta,g,b)+\delta+\varepsilon$：$\theta$为生理参数，$g$为几何，$b$为边界，$\delta$为模型偏差，$\varepsilon$为测量误差。

当几何或入口被错误固定时，优化器可能通过改变 $\theta$ 补偿差异，仍产生很小的残差。此时得到的是“当前模型假设下的有效参数”，不能自动作为组织真实材料参数。

局部灵敏度矩阵 $S=\partial F/\partial\theta$ 的列若近似线性相关，则存在 $\Delta\theta\ne0$ 使 $S\Delta\theta\approx0$：参数变化了，曲线几乎不变。这是低敏感方向和参数补偿的数学表达。神经网络加速 $F$ 不会自动提升 $S$ 的秩。

一个直观例子是平均压差近似 $\Delta\bar P=R\bar Q$。只知道平均压，$R$与$\bar Q$可以互相补偿。再加脉压仍需管壁、入口形状等假设。此式是读者用简化示意，不能替代完整脉动模型。

## 3. 两篇几何论文为何并不矛盾

Bartolo改变网络数量、节点位置和管段半径，结构树也随末端几何改变；Bošnjak固定出口面和Windkessel，主要改变表面局部起伏。整段半径偏移与局部零均值粗糙度不是同一种误差。

作为物理直觉，在理想Poiseuille条件下 $R=8\mu L/(\pi r^4)$，一阶变化 $\Delta R/R\approx\Delta L/L-4\Delta r/r$。这说明系统性管径偏差会显著改变阻力，但它不是本文两套脉动复杂网络的精确误差公式。

比较研究结果时应对齐：扰动空间尺度、是否有均值偏移、几何间相关性、出口是否联动、柔壁还是刚壁、点值还是区域平均、标准差还是置信区间。

## 4. 按观测条件决定反演范围

| 已有观测 | 可以尝试的起点 | 暂不能据此声称 |
|---|---|---|
| SBP、DBP、HR | 极简模型和少量有效参数；先检验非唯一性 | 全血管树刚度／阻力都可辨识 |
| 加cfPWV与人口学 | Bikia式低维缩放与SV验证 | 完整入口波形准确或危重病适用 |
| 加压力与流量完整波形 | 集总模型参数子集与SSRM | 九参数在真实噪声下一定稳定 |
| 加静脉压力 | 改善静脉／舒张充盈相关约束 | 不需要考虑静脉压测量误差 |
| 几何＋多部位MRI流量 | 1D网络、分组刚度、显式后验 | 几何已精确、中央血压已独立验证 |

## 5. 建议研究方案

### 阶段A：明确问题与最小模型

选择主要终点：SV、主动脉压力、总体顺应性或分组刚度。列清实际可得观测、位置、单位、采样时刻和误差。先建能回答问题的最小模型，固定值给出来源及不确定性范围。

### 阶段B：合成反演与可辨识性

生成多个参数真值，分别测试无噪声、加性噪声、乘性噪声、时间相关噪声与时相偏移。计算局部敏感性、参数相关性；有条件再进行结构分析、剖面似然和全局敏感性。比较指标与波形、不同观测部位和参数子集。

不仅给平均误差，还给最差情况、失败比例、参数边界命中率与多初值差异。固定参数分别取准确值与偏移值，确认模型能否承受现实先验误差。

### 阶段C：联合几何与边界误差

重复分割或构建合理几何样本，保留父子血管协方差和病理形态。将几何与入口误差传播到参数后验；至少进行多套合理几何下的重复反演，观察临床解释是否改变。

### 阶段D：需要时才引入代理

若原求解器足够快，先完成原模型反演。只有重复求解确实限制研究时，再引入参数条件化代理。训练／验证／测试按参数样本划分，不能把同一波形的不同时间点随机分割后当作独立泛化测试。

### 阶段E：临床验证

保留没有参与损失、先验范围设置、模型选择或阈值调节的观测。分别报告相关、MAE／RMSE、Bland–Altman偏差与LoA、误差随真值的变化，以及区间覆盖与宽度。动态监测另测趋势跟踪，不能用一次静息结果替代。

## 6. 一个可检查的统一目标函数

以下是建议形式，**不是六篇论文共同使用的原式**：

$$J(\theta,g,b,\eta)=\tfrac12r^T\Sigma(\eta)^{-1}r+\tfrac12\log|\Sigma(\eta)|-\log p(\theta,g,b,\eta),$$
$$r=y-F(\theta,g,b).$$

若只做MAP，求 $J$ 最小点；若需要可信区间，对相应联合后验采样。几何固定时得到的是条件后验 $p(\theta\mid y,g_{fixed},b_{fixed})$；几何不确定时应考虑边缘化：

$$p(\theta\mid y)=\int p(\theta,g,b,\eta\mid y)\,dg\,db\,d\eta.$$

不要先承诺所有量联合可辨识；增加未知量后，仍须检查观测是否足够。先验强约束得到窄区间，也不代表数据本身有足够信息。

## 7. 真正有价值的潜在创新

以下为研究假设，需实验后才能称创新：

1. 联合传播几何与入口不确定性的参数条件化代理，检验是否修正现有条件后验的过度自信。
2. 用期望信息增益等原则选择最有价值的额外观测，而不仅增加数据总量。
3. 把“拟合准确但参数错误”的失败样本系统公开，比较代理、噪声模型和固定参数处理的影响。
4. 用真正独立压力或流量验证，并检验跨病理、跨中心、跨时间的预测稳定性。

创新论证应针对已有工作缺口，不能仅把PINN、贝叶斯、血压三个词组合就称方法创新。

## 8. 中英术语与容易混淆的概念

| 英文 | 中文 | 关键区别 |
|---|---|---|
| calibration | 校准／参数标定 | 用观测估参数 |
| validation | 验证 | 检查未参与校准的观测或目标 |
| verification | 数值核验 | 检查方程和离散实现是否正确 |
| structural identifiability | 结构可辨识性 | 理想观测下的唯一性 |
| practical identifiability | 实际可辨识性 | 有限含噪数据的约束程度 |
| compliance | 顺应性 | 压力变化引起的容积／面积变化，须注明定义 |
| elastance | 弹性／容积弹性系数 | 常与容积顺应性互为倒数，但须同一模型定义 |
| distensibility | 可扩张性 | 常是按参考容积／面积归一化的顺应性 |
| model discrepancy | 模型偏差 | 模型结构与真实系统的差异 |
| emulator / surrogate | 代理模型 | 近似正向求解器 |
| forward UQ | 正向不确定性量化 | 输入分布传播到输出 |
| inverse UQ | 逆向不确定性量化 | 从观测推断参数分布 |
| confidence interval | 置信区间 | 重复抽样程序的覆盖性质 |
| credible interval | 可信区间 | 给定数据和先验的后验概率区间 |
| prediction interval | 预测区间 | 包含新观测噪声，通常更宽 |
| LoA | 一致性界限 | 方法间个体差值范围，不是均值的置信区间 |
| stressed volume | 受压血容量 | 不等于全身总血容量 |

本文依据各篇精读中的原文页码与公式，不增加未经核验的临床效能结论。
